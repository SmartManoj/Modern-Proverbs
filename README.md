# Modern Proverbs

Old proverbs, corrected. Many classic sayings trade accuracy for a nice ring — this repo keeps the wisdom but fixes the wrong word.

Inspired by [this thread](https://www.reddit.com/r/PetPeeves/comments/1sdhmsy/there_is_no_way_slow_and_steady_wins_the_race_is/) arguing "slow and steady wins the race" is just wrong.

## The list

One file per proverb in [`proverbs/`](proverbs/).

## Contributing

Open a PR adding a file to `proverbs/` (copy an existing one for the format). Keep it: a real proverb, one precise word swapped, and a one-line reason the original is loose or wrong.
